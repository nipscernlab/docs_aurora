# Atalhos de teclado

## Personalizáveis

Uma tabela só, regravável em {guilabel}`Configurações`, aba {guilabel}`Atalhos de Teclado`: clique no atalho e pressione a combinação nova. A mesma tabela alimenta a paleta de comandos, então tudo aqui também se acha pelo nome.

| Padrão | Ação |
|---|---|
| {kbd}`Ctrl+N` | novo arquivo |
| {kbd}`Ctrl+S` | salvar o arquivo atual |
| {kbd}`Ctrl+Shift+S` | salvar todos |
| {kbd}`Ctrl+W` | fechar a aba ativa |
| {kbd}`Ctrl+Shift+T` | reabrir a última aba fechada |
| {kbd}`Ctrl+Alt+N` | novo projeto |
| {kbd}`Ctrl+Shift+O` | abrir projeto |
| {kbd}`Ctrl+Alt+B` | backup do projeto |
| {kbd}`F5` | compilar tudo |
| {kbd}`F6` | compilar C± |
| {kbd}`F7` | sintetizar Verilog |
| {kbd}`F8` | simular com forma de onda ({guilabel}`Analisar Verilog`) |
| {kbd}`F9` | simulação rápida, sem onda |
| {kbd}`F10` | abrir o PRISM |
| {kbd}`Shift+F5` | cancelar a compilação |
| {kbd}`Ctrl+Shift+H` | histórico de compilações |
| {kbd}`Ctrl+Shift+L` | limpar o terminal |
| {kbd}`Ctrl+Alt+P` | Hub de Processadores |
| {kbd}`Ctrl+Shift+C` | abrir as Configurações |
| {kbd}`Ctrl+Alt+S` | ligar e desligar a análise semântica de Verilog |

## Fixos

| Atalho | Ação |
|---|---|
| {kbd}`Ctrl+K` | abre e fecha a Aurora Intelligence |
| {kbd}`Ctrl+Shift+K` ou {kbd}`Ctrl+Shift+P` | paleta de comandos |
| {kbd}`Ctrl+Shift+F` | buscar nos arquivos do projeto |
| {kbd}`F2` | abre a pasta do projeto no explorador |
| {kbd}`Ctrl` + {kbd}`+` / {kbd}`-` / {kbd}`0` | zoom da janela |
| {kbd}`Esc` | fecha o modal aberto |

## No Simular do PRISM

Valem com o foco no diagrama, fora de campos de texto.

| Atalho | Ação |
|---|---|
| {kbd}`Espaço` | rodar e pausar |
| {kbd}`→` | avança um tick |
| {kbd}`Shift+→` | salta ao próximo evento |
| {kbd}`Esc` | tira o cursor de tempo; sem cursor, sobe um nível de submódulo |

## No editor

| Atalho | Ação |
|---|---|
| {kbd}`Ctrl+F` | localizar no arquivo |
| {kbd}`Ctrl+H` | localizar e substituir |
| {kbd}`Ctrl+G` | ir para a linha |
| {kbd}`Shift+Alt+F` | formatar o documento |
| {kbd}`F12` | ir para a definição |
| {kbd}`Alt+F12` | espiar a definição |
| {kbd}`Shift+F12` | listar referências |

## Na árvore, visão Pastas

| Atalho | Ação |
|---|---|
| {kbd}`F2` | renomear |
| {kbd}`Delete` | mover para a lixeira ({kbd}`Shift+Delete` apaga em definitivo) |
| {kbd}`Ctrl+C` / {kbd}`Ctrl+X` / {kbd}`Ctrl+V` | copiar, recortar, colar |
| {kbd}`Ctrl+Z` / {kbd}`Ctrl+Y` | desfazer e refazer |
| {kbd}`Ctrl+clique` / {kbd}`Shift+clique` | seleção múltipla: soma um, ou pega o intervalo |
| {kbd}`Ctrl+A` | seleciona o que está visível |

Arrastar com {kbd}`Ctrl` pressionado copia em vez de mover.

## No painel da IA e nos terminais

| Atalho | Ação |
|---|---|
| {kbd}`Enter` | envia a mensagem ({kbd}`Shift+Enter` quebra linha) |
| {kbd}`Ctrl+C` no TCMD | copia a seleção; sem seleção, interrompe o comando |
| {kbd}`Ctrl+V` no TCMD | cola |
